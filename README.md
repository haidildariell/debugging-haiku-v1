One haiku about debugging, strict 5-7-5 syllables, at most 200 characters.
A flaky test passes on retry with no code changed — and the last line turns
the poem: it was luck all along, dressed up as science.

Run `python3 main.py` with `ENTRY_OUTPUT_DIR` set (or `/output` by default)
to write `entry.txt`.
